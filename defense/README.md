## Доказательства

В `evidence/build.log` убраны только пробелы в концах строк. `ha.log` фиксирует сквозной прогон, `restore-cold.log` — последующую проверку с запуском остановленного restore-инстанса.

`evidence/records.json` хранит реальные HTTP-ответы, SQL, вывод Compose, сетевые подключения и результаты проверок. `ha-report.json`, `ha.log` и `restore-cold.log` содержат результаты аварий и восстановления. JPG являются снимками работающего интерфейса либо HTML-отчётов, составленных из вывода реально выполненных команд. Отчёты так и обозначены; это не имитация терминала.

Снимок `frontend-desktop.jpg` получен до повторного HA-прогона. Число операций в UI на нём и в итоговом backup различается, потому что тесты добавляют демонстрационные записи. Снимки отчётов иногда показывают выбранные поля HTTP/Compose или одну таблицу iptables; полный исходный вывод находится в JSON и `*-iptables.txt` / `*-ip6tables.txt`.

Проверка 15.11.2026:

| Проверка | Результат |
|---|---|
| Сборка и запуск Compose | 16 основных контейнеров healthy, плюс restore |
| CRUD, валидация, свежие данные после PUT/DELETE | PASS |
| Сети, ALLOW/DENY, REJECT-счётчики, кэш, consumer | PASS |
| Запрет нужного соединения operations с БД | 200 / 503 / 200, временное правило удалено |
| SIGKILL primary PostgreSQL | pg3 переключился на pg1, 20,922 с |
| SIGKILL лидера RabbitMQ | rabbit2 переключился на rabbit1, 8,978 с |
| Restore с запуском остановленного инстанса | 4,148 с, все поля 21 операции совпали |

Параметры SLO/MTBF остаются целями, а не подтверждённой эксплуатационной статистикой. Модель HA ограничена одним отказом узла при работающем Docker-хосте и доступном кворуме.

## Перед сдачей

Анонимный запрос GitHub API 15.11.2026 вернул 404 для `yusufsharp/project-finance-app`. Поэтому публичный доступ не подтверждён. Для требования открытых исходников нужно проверить репозиторий без авторизации либо передать преподавателю доступную ссылку на архив. Сам Git push не меняет видимость репозитория и не создаёт публичную ссылку на скачивание.

Приложение работает локально: http://127.0.0.1:8080/. Публичного URL приложения нет. Локальный запуск разрешён требованиями защиты.

Архив обновляется командой `python3 scripts/package_source.py`. В нём нет `.env`, `.git`, Docker volumes, резервных копий, пользовательских записей, слайдов и исходных учебных PDF. Внутри есть `SHA256SUMS.txt` для файлов исходников. Проект запускается после распаковки и `python3 scripts/start_hw5.py` из каталога `finance-tracker`.

Ранняя презентация в `output/defense/` относится к старой архитектуре. Для сдачи используйте файлы этого каталога `defense/`.
